# Kerr Studio · TRPL 采集界面

> 本文记录接入后端之前的界面原型与历史验证。当前已接入模拟后端，实际使用及功能边界见 [README.md](README.md)；下文“未写入文件”“不执行拟合”等描述仅适用于早期原型。

界面已统一为英文（`lang="en"`），包括导航、按钮、坐标、动态状态、分段校验、对话框、提示及无障碍标签。主导航使用 Acquisition、Analysis、Spectral Calibration；图表为 Live Spectrum 与 TRPL Map & Decay。现有配色、三行滚动列表、固定模式高度和色标右对齐保持一致。

亮色主题的 Ready、Connected 和 In position 状态圆点改为更鲜亮的绿色 #22c55e；状态文字仍使用次要文字色，深色主题沿用原色板。

本地打开 index.html 即可查看交互原型。所有图表、设备状态、移动过程、背景和寿命参数均为演示；未连接硬件，不向展示的 HDF5 路径写入文件，不执行实际寿命拟合。界面通过统一徽标标识演示模式；导出的 CSV 仍保留 DEMO 文件名和数据来源说明。

## 当前界面

- 顶端展示采集进度与开始、暂停、继续、停止操作。停止按钮可用时呈危险色，运行与暂停时实验参数锁定。
- 采集工作台、数据分析和光谱校准采用独立页面导航；后两页仅保留标题，暂时留空。切换页面不终止采集。
- 延迟台采用可编辑绝对延迟读数，输入后按 Enter 或点击“移动”。步进移动恢复为 −1、−0.1、+0.1、+1 ps 四个预设按钮。移动期间显示“移动中”，完成后显示“已到位”，并阻止重复移动与启动扫描。连接、到位与采集状态统一以圆点标记，灰色文字搭配彩色状态圆点。
- 曝光和中心波长并排，单位作为输入框内后缀。高级设备设置收起，整行标题可点击。
- 分段列表每段设置起点、终点、步长，提供添加及删除。列表校验空值、非正步长、终点小于或等于起点、区间重叠与段间不相接，错误时标识对应行并禁用开始。公共端点自动去重，每轮最多 5,001 点、最多 10 段。单次模式采集当前位置，重复模式重复多轮扫描。
- 实时光谱图例旁提供“采集背景”，采集后叠加背景曲线，不展示单独的背景状态行。光谱以 CCD 原始 counts 展示，显示满量程虚线；仅当饱和像素数大于零时，在“实时光谱”标题右侧以警告色展示计数。
- 下方二维图与右侧衰减图共用纵向延迟坐标，零点和绘图区上下边界对齐。点击光谱或二维图选择波长，窗口固定为 ±5 nm。拟合开关和 τ₁、τ₂ 参数放在右侧衰减绘图区内，控制模型曲线及参数显隐。收紧标题工具、色标与绘图区之间的垂直间距。
- 底部路径可编辑，“未写入磁盘”等采集状态以灰色纯文字显示，不使用输入框或按钮式边框。自动保存为界面选项，CSV 导出可下载合成衰减数据。

## 视觉规则

低饱和深色面板，细外框；绘图区采用独立深色底与接近网格明度的 1 px 边界。正文 15 px，常用控件 14–15 px，标题 17 px，坐标与图例 14 px。鼠标删除目标为 36 px，触屏目标提升为 44 px，高级设置整行点击目标至少 44 px。保留浅色主题与窄屏布局。

颜色职责：亮蓝仅用于交互和选中态；数据曲线为青色；背景光谱、拟合模型和参考线为琥珀色，并以虚线长度和图例区分；波长光标为浅灰白（浅色主题使用深灰）。拟合采用琥珀虚线叠加于青色数据线上。成功绿、警告琥珀、危险红均配合文字与图标，分别用于到位/完成、暂停/饱和、停止/校验错误。

热图采用靛蓝—青绿—浅青渐变，低值端抬亮，与绘图区背景分开。待采集区域使用独立底色与斜线填充，不与弱信号混淆。色标同步使用同一组颜色。

contrast-report.json 记录浏览器计算的主界面 80 项可见文字/控件及坐标标签的对比度检查，禁用控件不计入。当前深色最低 6.47:1、浅色最低 5.68:1；计算包含半透明背景合成。该检查覆盖当前显示状态，不替代全部动态状态的无障碍审计。

## 数据与实现边界

1. 光谱采用 2,048 个合成像素，原型按 16 位满量程 65,535 counts 截断；曝光和当前延迟会改变合成信号，饱和计数根据截断前信号计算。此阈值不是对实际 CCD 的规格确认；正式版本应从设备位深、增益及读出设置读取实际满量程。
2. 背景采集为合成暗计数曲线；实际采集流程应根据快门及光路定义背景条件。
3. τ₁ = 0.42 ps、τ₂ = 3.80 ps 为合成信号模型参数，勾选拟合展示模型及参数，不执行数值优化。正式分析需提供实测 IRF 卷积、残差、置信区间与拟合范围。
4. 二维图的 Log 仅控制强度色标；延迟轴保持线性，包含负延迟及零点。衰减图横轴为波段平均强度，纵轴为延迟。
5. 扫描采用加速演示，预计曝光时间不包含位移稳定、读出和写入开销；演示移动耗时不代表真实机械性能。

接入硬件前需明确机械行程、位移—延迟换算、移动确认、相机 ROI/FVB 约束、背景条件与文件写入机制。实际数据应保留每点位置、时间戳、曝光、零点版本及设备配置，并在写入成功后才显示“已保存”。

## 验证

通过本地无头 Edge 检查绝对与相对移动、移动状态、τ 显隐、独立页面、背景采集、饱和计数、分段增删及重叠/倒序校验、公共端点去重、停止按钮危险色、参数锁定、CSV 导出，以及 1440 / 1024 / 390 px 宽度下的横向溢出。浏览器未报告脚本错误。

当前深色主题采用用户指定色板：页面 #0b1220、卡片 #111a2b、绘图区 #0a1322、操作 #6f9bff、数据 #4cc3d9、拟合/背景/参考 #e0a84a、成功 #5fd08a、危险 #ff6b6b、正文 #d7e0ee、次要文字 #9aa8c2。危险按钮使用深色文字以保持对比度；热图以靛蓝、青蓝、浅青过渡。

布局更新：色标加长，置于“时间分辨光谱与衰减”的标题行，移除原先为色标预留的独立垂直间距；光谱和二维图的纵轴标题移到左侧旋转显示，减少顶部占用，并增加实时光谱的高度。分段扫描每行的起点、终点、步长与删除按钮横向连成一组，组内无空隙，行间保留间距。列表最多同时显示三段，超出后在列表内滚动。采集方案为分段列表与循环轮数预留固定空间，按重复模式的高度布局，切换单次、扫描、重复时不改变背景框高度。顶栏缩减产品区宽度和间距，延长进度条。
