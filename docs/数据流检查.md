# Analysis / Spectral Calibration 数据流检查

2026-10-31：后端、前端接口契约和数据保存链路检查通过。本轮未打开浏览器、WebView 或桌面软件窗口，未连接仪器，不包含视觉、鼠标操作和真实硬件验收。

## Analysis

前端从 `/api/v1/status` 取得当前实验、该实验的标定和历史拟合，从 `/runs/{run_id}/records` 分页取得已提交帧。拟合选项由 `frontend/analysis.js` 生成，`frontend/app.js` 提交 `POST /runs/{run_id}/fits`，再查询 `GET /tasks/{task_id}`。后端任务返回 running / completed / error；失败原因由前端显示。

后端只读取**该实验采集时冻结的波长轴**，在窗口内对像素原始计数取均值，再除以对应曝光，按延迟对所有帧和轮次平均。拟合起止延迟、模型和高斯 IRF 宽度由请求传入。显示背景扣除和 Acquisition 的轮次选择不改变 Analysis 的原始数据处理。结果包含 observed / predicted / residuals、参数和局部误差估计、请求选项、run_id、task_id 和时间；前端单位为 counts/s，拟合 CSV 也使用这些数组。

已修正的数据流问题：

- 保存内存实验和拟合完成写入使用同一同步锁。无论先保存还是先完成拟合，结果都进入 `/analysis/{task_id}`，避免写文件过程中只更新内存。
- 前端确认运行 ID 和选项仍匹配，避免把旧任务结果显示到新实验或已改动的选项下。
- 页面刷新后，轮询能发现随后完成的拟合；已显示或已清除的结果不会每次轮询重新覆盖用户参数。
- 旧实验缺少标定时明确提示该实验无法按 nm 拟合；当前新标定仅用于未来采集，不追溯修改旧实验。

检查覆盖真实任务轮询、选项传递、观测值重算、残差恒等关系、HDF5 写入与重开、无标定错误、非法时间范围，以及拟合与保存交错执行。误差仍是局部 Jacobian 的近似，不是严格置信区间。

## Spectral Calibration

| 前端操作 | 接口（均以 `/api/v1` 为前缀） | 后端数据与约束 |
|---|---|---|
| 恢复当前帧 | `GET /calibration/frame` | 返回当前缓存的模拟全图，未采集时为 null；不会自动曝光 |
| Acquire frame | `POST /calibration/frames` | exposure_s / seed → 255×1024 int32 模拟计数、frame_id、曝光和手动光谱仪设置记录 |
| 修改行范围、Find peaks | `POST /calibration/extract` | frame_id / row_start / row_end → 1024 点均值谱、亚像素峰位置、ROI 饱和像素数；行范围为含首尾 |
| Fit pixel → wavelength | `POST /calibration/fit` | 帧 ID、行范围、启用的像素—波长配对、阶数、参考来源和 air/vacuum 约定 → solution_id、1024 点轴、系数、残差、RMS、覆盖范围与警告 |
| Apply to acquisition | `POST /calibration/apply` | 仅提交 solution_id；服务端从缓存取得已验证结果，检查帧及手动设置仍匹配，原子保存后更新当前标定 |
| Export calibration JSON | `GET /calibration/solutions/{solution_id}` | 从后端取得同一解及真实 applied 状态，再由前端下载；保留来源、帧头、配对、ROI、系数和误差 |

拟合用归一化像素的最小二乘，支持 1–3 阶，至少需要“阶数 + 2”条启用谱线。拒绝重复像素/参考波长、病态矩阵、非正或非有限轴、1024 点及其间连续区间上的折返。支持递增和递减波长轴；残差为参考值减模型值。未被参考谱线覆盖的区域标注外推。air/vacuum 仅记录约定，不执行自动换算。

所有相机图像在后端生成；前端保留绘图和人工谱线配对，不再自行生成 CCD 帧、提谱、找峰或计算拟合解。修改配对、阶数、ROI 或约定会撤销当前草稿；重新采帧或更改光谱仪记录会使旧帧/解过期。采集繁忙时拒绝校准采帧和应用操作。ROI 饱和时拒绝拟合。输入和写入沿用本地会话鉴权。

安装标定及手动设置记录保存在 `data/installed-calibration.json`，以临时文件加原子替换写入。重启时一起恢复；文件损坏则停用标定并保留错误说明，不把损坏文件解释成有效标定。当前原始校准图像和未应用草稿只缓存在内存中，重启后需要重新采帧/拟合。导出 JSON 保留帧头和标定结果，不包含整张 CCD 原图。

应用标定 → 开始新采集 → 实验 metadata → HDF5 `/calibration` → Analysis 读取波长轴的链路已验证；已有实验的标定保持不变。全图模式仅是模拟校准功能，不代表真实 Newton image 模式已经接通。示例参考线是演示数据，不是灯谱数据库；模拟帧产生的解始终标为 synthetic，即使导入了用户参考 CSV。

## 顶栏锁定

Analysis 的顶栏保持实时更新，Start / Stop 按正常设备状态启用，不因页面选择而锁定。

Spectral Calibration 与采集互斥：后端忙碌（包括运行、暂停、停止收尾期间）时，校准按钮、输入、谱线配对和图内编辑禁用；顶栏显示实时采集进度，并允许正常暂停/恢复/停止。空闲后校准控件恢复原有条件限制，顶栏进度和 Start / Stop 锁定。采集结束时先更新最终进度，再冻结，避免停留在过期百分比。后端提谱与校准拟合也会拒绝忙碌时的请求。已有采集不会因页面切换而取消、暂停或重启。
