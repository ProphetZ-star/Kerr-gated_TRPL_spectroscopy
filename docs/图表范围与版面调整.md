# 图表范围与版面调整

2026-11-01，仅修改 Codex 工作目录的 `kerr-trpl`。当时未同步桌面副本或 GitHub。

1. 移除全部绘图区的向内刻度及其公共绘制模块；数值标签和图框保留。
2. 无数据和有数据的绘图区统一使用 Extracted spectrum 的 --plot 配色。亮色模式为 #e4edf7 淡蓝；暗色模式统一使用对应的深色谱图配色。CCD 和 TRPL 热图中的实际图像/强度颜色保留，不覆盖成纯色。
3. Live Spectrum、TRPL Decay 在空白和有数据时均显示主网格：各方向分成四个大间隔，不绘制次级细网格。TRPL Map 继续无网格。
4. CCD frame 显示实际后端模拟帧图像，空白和有图像时都不叠加网格；ROI 带和选区边界保留。缩放图像后仍使用真实像素/行坐标选取 ROI。
5. Live preview / Stop preview 移到 Acquisition 标题栏右侧；完整移除 Additional settings 及其界面内容。采集仍使用合法默认参数，并可恢复实验中记录的曝光、重复次数、每点帧数等参数；旧故障注入记录不会自动带入新扫描。波长窗口通过 Analysis 控件调整，实时谱图仍可点击选波长；显示默认汇总所有轮次且不扣背景。
6. Fit parameters 与 Line assignments 使用同一高度变量（190–240 px，随视口调整），表格超出部分在面板内滚动，将更多空间留给上方光谱。小窗口/纵向布局也采用相同的摘要面板高度。
7. 九张图右上角增加 Axes…：可以分别关闭 Auto X / Auto Y，并编辑最小值和最大值；Reset to auto 恢复自动范围。有限值且最大值必须大于最小值，无效输入不应用。范围仅保留于当前前端会话，不修改原始数据、采集计划、拟合输入或保存文件。

共享坐标关系保留：Map 与 Decay 的延迟轴联动；Analysis 主图/残差的延迟轴联动；标定映射/残差的像素轴联动。线性/对数及像素/nm 的设置分别保存，防止跨单位混用。CCD 行坐标保持向下递增；对数图编辑的是图上显示的 log₁₀ 坐标值。曲线、图像、谱峰选择和 ROI 点击使用同一套显示变换。
