# 界面易用性修改

2026-10-31，仅修改 Codex 工作目录的 `kerr-trpl`，当时未同步桌面下载副本或 GitHub。

1. 桌面启动先使用实际 index.html 和内联本地样式显示工作台，灰色禁用界面上叠加旋转等待图标。该启动页不请求后端、不加载采集脚本。后端就绪后切换到工作台，首次状态获取成功才解除遮罩；网页初次连接失败会显示错误和重试按钮。
2. 模式徽标改成按钮，提供 Simulation / Real hardware。忙碌时禁止切换；选项调用 `/devices/connect`。真实硬件尚未完成适配，后端会明确拒绝并保留模拟状态，不会把模拟数据标记成实测。
3. 底栏输入改为 File name，默认 Sample 01 TRPL，自动补 `.h5`。目录独立保存，默认项目 data。App 使用系统文件夹选择器；网页入口提供目录路径输入。目录和文件名组合后传给原有采集、HDF5 保存接口；拒绝文件名中的路径及 Windows 保留字符，不覆盖已有文件。
4. 顶部样品名称跟随文件名输入，恢复实验时读取其保存文件名。
5. 亮色无数据背景统一为 #bfc3c9；暗色无数据背景使用 Live Spectrum 的 --plot。TRPL Map 未采集区域始终保持该背景，绘制已有数据后也不叠加网格。Live Spectrum / Decay 无数据时使用相同背景。
6. 校准页没有采集数据时照常绘制空 CCD、光谱及映射图框。标题改为 CCD frame / pixel、Extracted spectrum / pixel（波长显示为 / nm）；删除底部重复单位和操作提示。ROI 饱和计数只在非零时以警告色显示在 CCD 标题旁，空白图上的点击不提交提谱或配对操作。
7. 映射与残差保持相同的像素范围、左右边界和刻度位置，残差不重复显示横轴数字；RMS、最大残差和覆盖范围移到上方映射图内。
