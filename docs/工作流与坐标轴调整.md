# 工作流与坐标轴调整

2026-11-01，仅修改 Codex 工作目录的 `kerr-trpl`，当时未同步桌面副本或 GitHub。

1. Live Spectrum、TRPL Decay 有数据和无数据均使用同一个背景变量：亮色为 #bfc3c9，暗色沿用深色绘图区。
2. 自动采集保存及 Analysis 的 Save HDF5 均先检查目标文件族。已有同名 `.h5`、`.partial.h5`、`.stopped.h5` 或 `.events.jsonl` 时弹窗列出冲突，用户可选择覆盖或取消。确认绑定到当前文件的大小、修改时间和文件标识；文件变化后要求再次确认。确认覆盖会将旧文件移入同目录的 `.<文件名>.overwrite-backup-*` 文件夹，再创建新文件；旧备份保留，不自动删除。新文件初始化失败时会恢复原文件，不能恢复到原位置的文件仍保留在备份目录。
3. 再次开始采集时默认替换 memory-only 实验，无需先手动 discard。取消覆盖、参数错误或新文件创建失败不会提前丢弃旧内存记录。自动保存的初始文件建立成功后才替换旧实验；若有分析任务正在运行，先完成或取消该任务。
4. Set zero t₀ 保留确认及重定义零点功能；新增 Go to t₀，发送绝对延迟为 0 的移动请求，不改变零点定义或版本。
5. Analysis 的 Decay & fit 删除底部重复说明。横轴单位和数字保留在上方衰减图，残差沿用相同延迟范围及横向位置，不重复显示横轴数字。
6. Experiment 的 Open… 在 App 中打开系统 HDF5 文件选择器，取消不改变实验。网页入口使用浏览器文件选择器，上传本地副本后打开；原文件不改写，导入副本保存在项目 data/imports，单文件上限 256 MiB。无效导入会清理临时副本并保留当前实验。
7. Fit controls 的 Wavelength 使用任意小数步长，避免点选波长因不满足 0.1 nm 步长而出现无效红框；输入边框采用统一颜色，真正无效的输入仍保留错误提示。
8. 校准页 CCD 和提取光谱面板使用相同高度、相同标题区高度；窄窗口的对应行高也保持一致。九个绘图区共用向内刻度绘制函数，包括横纵轴、反向延迟轴和 CCD 行坐标。
