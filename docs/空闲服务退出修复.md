# 桌面退出时清理复用的空闲后端

2026-10-31：此前桌面退出只回收自己启动的后端；若复用了 browser.py 启动的后端，关闭窗口后服务仍会运行并占用端口。

现在关闭已成功启动的桌面窗口时，也在后台检查复用服务。仅对当前目录、当前代码版本、同一进程及 worker session 发出 `/api/v1/service/stop-if-empty` 请求。检查及请求失败时允许窗口退出并保留服务，不强杀进程。

后端只有在无活动操作、无任何已加载/采集实验（包括已保存实验）、无背景数据、无校准图像草稿且无运行/排队拟合任务时才接受自动关闭。磁盘上已有的历史文件不阻止空服务退出。确认条件和冻结后续命令在同一 worker 锁内完成，避免检查后又接受新采集。正常退出会释放设备进程、服务宿主和监听端口。

自己启动的服务仍采用原有的退出确认及数据保护流程。其他目录的服务不会因本窗口退出而被自动关闭。网页标签关闭不触发清理；已有实验时复用服务仍会保留，可先保存/丢弃并通过 stop-web.cmd 主动停止。

专项回归：27 项通过，包含新规则、服务身份变化、并发采集防护、后台关闭回调、原有桌面关闭逻辑及真实隐藏后端/网页宿主同时退出。真实启动位于隔离临时源码目录，不与用户服务共用实例锁。未打开浏览器或桌面窗口，未连接仪器，未运行完整套件。
